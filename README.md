# 做题区

一个用来尝试想法的 AI slop。不知道起什么名字才起的名字

代码有认真审阅和测试 : )

等以后有空再正经重写吧

Android 离线刷题应用, 支持导入 Ginkgo 和 Holly 题库

[下载安装包](https://github.com/GuChL9/zuotiqu-releases/releases/latest) · [反馈问题](https://github.com/GuChL9/zuotiqu-releases/issues)

支持 Android 7 及以上, 可在 设置 > 关于 中检查更新

记录保存在本机, 更新请直接覆盖安装, 不要先卸载旧版
